# Komodo Control Center for Windows

This contribution adds a Windows batch control center for local Komodo management.

## Goals

- One-click start, stop, restart and dashboard access
- Diagnostics and health checks
- Docker and Core logs
- Windows shortcut and startup integration
- Local user/admin maintenance helpers
- Optional live PT-BR UI translation helper
- Built-in action/error logging with optional Windows notifications
- Built-in beginner guide covering Komodo resources and workflows
- Safe GitHub contribution flow through fork and Pull Request

## Safety

The script avoids committing unrelated local repository files when publishing updates.
Destructive operations require explicit confirmation.

## Usage

Run `KOMODO_CONTROL_CENTER.bat` on Windows and use the numbered menu.
The default local dashboard expected by the script is `http://localhost:9120`.
